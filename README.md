# Minecraft 1.21 (Tricky Trials Edition) PWA

[![Deploy to GitHub Pages](https://github.com/SHARVANKUMARSINGH/Minecraft1.20/actions/workflows/deploy.yml/badge.svg)](https://github.com/SHARVANKUMARSINGH/Minecraft1.20/actions/workflows/deploy.yml)

Play **Minecraft 1.21** directly in your browser with full **Android Touch Controls**, **Bedrock-style Virtual Joystick**, and **Progressive Web App (PWA)** offline support!

🎮 **Play Live in Browser:** 👉 **[https://sharvankumarsingh.github.io/Minecraft1.20/](https://sharvankumarsingh.github.io/Minecraft1.20/)**

---

## ✨ Features

- 📱 **Android & Mobile Touch Controls**:
  - **Bedrock-style Virtual Joystick**: 8-way analog movement with auto-sprint threshold.
  - **Touch Camera Pan**: Drag anywhere on the right side of the screen to fluidly rotate the camera.
  - **Action Buttons**: Dedicated touch buttons for Jump, Sneak (toggleable), Mine/Attack, Place/Use, and Drop.
  - **Quick Utility Bar**: Quick touch buttons for Inventory (E), Chat (T), Pause Menu (Esc), and Perspective (F5).
  - **Hotbar Quick-Select Bar**: Directly tap hotbar slots 1 through 9.
- 💻 **Desktop Mode Support**:
  - One-click HUD toggle between **📱 Mobile Touch** and **💻 Desktop Keyboard & Mouse**.
- 🔴 **1.21 Tricky Trials Loading Screen**:
  - Mojang Studios splash screen with dynamic progress indicator and smooth transition into the game world.
- ⚡ **Offline Progressive Web App (PWA)**:
  - Installable on Android, iOS, Windows, macOS, and ChromeOS.
  - Pre-cached assets enable fast loading and offline play.
- 🌍 **Multiplayer Support**:
  - Connect to online servers and public relays directly from the browser.

## 📲 How to Install as an App

### Android & Tablets
1. Open [https://sharvankumarsingh.github.io/Minecraft1.20/](https://sharvankumarsingh.github.io/Minecraft1.20/) in Chrome or Brave.
2. Tap the popup **"Install Minecraft 1.21"** or tap the browser menu (⋮) -> **"Install app"** / **"Add to Home screen"**.
3. Launch from your home screen with fullscreen Android touch controls!

### iOS & iPadOS
1. Open the URL in Safari.
2. Tap the **Share** button -> **"Add to Home Screen"**.

### Desktop (Chrome / Edge)
1. Open the URL.
2. Click the **Install** icon in the browser address bar.
3. Enjoy standalone windowed or fullscreen gameplay with keyboard and mouse!

---

## 🛠️ Local Running

Run a local HTTP server:
```bash
python3 -m http.server 8000
```
Then open `http://localhost:8000/` in your browser.
